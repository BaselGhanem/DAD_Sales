# ملف المبيعات اليومي

ارفع ملف الاكسل داخل هذا المجلد باسم `Up.xlsx`

المسار الثابت: `data/Up.xlsx`

## التحديث اليومي

1. افتح مجلد `data` في GitHub
2. اختر `Add file` ثم `Upload files`
3. ارفع النسخة المحدثة باسم `Up.xlsx` لاستبدال النسخة السابقة
4. اضغط `Commit changes`

احتفظ باسم صفحة البيانات `Data` وعناوين الاعمدة الحالية كما هي
ارفع الملف الكامل المحدث كل يوم، وليس حركات اليوم فقط
لا تحذف الملف القديم قبل الرفع، ارفع بنفس الاسم مباشرة

هذا المجلد مخصص لمصدر البيانات، ربطه بصفحة المندوب سيتم في المرحلة التالية
